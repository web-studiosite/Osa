====================================================================
OSA - OFFICIAL SHOP ADMINISTRATOR (PASTA PRONTA PARA DEPLOY)
====================================================================

Esta pasta (deploy/) contém todos os arquivos compilados e prontos para publicação
imediata em qualquer servidor, hospedagem ou GitHub Pages, sem necessidade de build:

PASTAS E ARQUIVOS:
- index.html                -> Página principal da aplicação
- css/style.css             -> Estilos visuais completos (Tailwind CSS compilado)
- js/app.js                 -> Lógica e código completo em JavaScript puro
- sql/supabase_schema.sql   -> Script SQL completo com todas as tabelas, índices e dados iniciais para o Supabase

COMO USAR NO GITHUB PAGES:
1. Suba os arquivos desta pasta para o seu repositório no GitHub.
2. Acesse: Settings -> Pages -> Selecione a branch 'main' e a pasta raiz '/' -> Salve.
3. O seu sistema estará no ar com link HTTPS em poucos segundos!

COMO USAR NO NETLIFY OU VERCEL:
- Basta arrastar/fazer upload desta pasta diretamente no site do Netlify ou conectar o repositório no Vercel.
